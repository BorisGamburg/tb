Итоговая логика закрытия Pyramid2:
1. Цена внутри Close Band — запускаем новый калькулятор частичного закрытия пары.
2. Цена полностью пересекла Close Band за один цикл — запускаем Band Cross Calculator.
3. Band Cross Calculator не смог построить безопасный план — запускаем старый альтернативный поиск.
4. Все остальные случаи — ничего не закрываем.
Следствие: старый альтернативный поиск больше не запускается при обычном нахождении цены за пределами Close Band. Он работает исключительно как fallback после неудачного Band Cross Calculator.

Частный тодо:
1. Запоминаем цену предыдущего цикла.
2. Получаем текущую цену.
3. Проверяем crossing всех Close Band соседних пар.
4. Если пересечена одна полоса — выбираем её.
5. Если пересечено несколько — для Buy выбираем самую нижнюю, для Sell самую верхнюю.
6. Рассчитываем план закрытия выбранной пары.
