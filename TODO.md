# Pyramid 2 — концепция режима сбора небольших движений

## 1. Основная идея

Стратегия должна регулярно забирать небольшие движения цены, не накапливать бесконечные убыточные хвосты и завершать каждый торговый цикл закрытием всей оставшейся позиции около безубытка.

Для этого используются два механизма:
- обычная фиксация прибыли по мере движения цены;
- существующий механизм Unwind + Rearm для компенсации убыточных уровней.

## 2. Построение пирамиды

- Первый уровень открывается по разворотному сигналу.
- Второй уровень разрешается открыть на стандартной дистанции одного шага. Для него действует исключение из проверки буфера.
- Первый уровень первоначально является якорем.
- Если впоследствии открывается уровень с более выгодной ценой (для Buy — ниже текущего якоря), он становится новым якорем.
- Все уровни имеют одинаковое количество, задаваемое конфигурацией.
- Минимальная дистанция между уровнями контролируется шагом сетки.

Уровни не обязаны располагаться последовательно по цене. Новый уровень может находиться ниже предыдущих, если появился соответствующий разворотный сигнал.

## 3. Работа выше суммарного безубытка

Когда текущая цена находится выше точки безубыточности всей оставшейся пирамиды (для Buy):

- Открываем новые уровни по сигналам стратегии.
- При открытии нового уровня закрываем предыдущий рабочий уровень с прибылью.
- Если подходящий уровень уже существует, используем его вместо повторного открытия.
- Перед каждым новым входом, начиная с третьего уровня, проверяем буфер.

### Проверка буфера

Перед открытием моделируем состояние всей пирамиды после добавления нового уровня.

Рассчитываем новую точку безубыточности и расстояние от текущей цены до неё.

Если запас движения против позиции меньше заданного значения — вход запрещён.

Буфер задаётся конфигурацией.

## 4. Работа ниже суммарного безубытка

Когда цена находится ниже точки безубыточности всей пирамиды (для Buy), используется существующий механизм:

**Unwind + Rearm.**

- Unwind подбирает прибыльные уровни-доноры.
- Их прибыль используется для компенсации убыточных уровней.
- Убыточные позиции могут закрываться полностью или частично.
- После успешного Unwind выполняется Rearm.
- Новый вход также учитывает ограничения буфера.

Существующий механизм Unwind не дублируется, а используется как часть новой логики.

## 5. Завершение торгового цикла

Независимо от того, откуда пришла цена — сверху или снизу, при достижении суммарного безубытка оставшейся пирамиды:

1. Закрываем все открытые уровни.
2. Учитываем комиссии и торговые издержки.
3. Завершаем текущий цикл.
4. Ожидаем новый разворотный сигнал.
5. Открываем первый уровень следующего цикла.

## 6. Основные параметры конфигурации

Предусматриваются:
- размер позиции одного уровня;
- шаг минимальной дистанции между уровнями;
- размер буфера;
- целевой PnL завершения цикла.

## 7. Главный принцип стратегии

**Выше безубытка — зарабатываем на небольших движениях.**

**Ниже безубытка — сокращаем убыточные хвосты посредством Unwind + Rearm.**

**При достижении безубытка — закрываем всю пирамиду и начинаем новый цикл.**

Это одна стратегия с двумя механизмами управления открытой позицией, а не две независимые стратегии.

Для Sell вся логика зеркально отражается.
